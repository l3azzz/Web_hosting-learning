#  Creating service file


	we don't use devolopment server we use production server

	what if our things get stoped we can't go every time and run it it fucks

	so we add wibbitz.service   its a task


		etc/systemmd/system



		[Unit]
		Description=gunicorn daemon
		After=network. target

		[Service]
		User=root
		Group=www-data
		WorkingDirectory=/home/django/wibbitz/src/wibbitz
		ExecStart=/home/django/wibbitz/venv/bin/gunicorn -access-logfile - -workers 3 -bind unix:/home/django/sock/wibbitz.sock wibbitz.wsgi:application

		[Install]
		WantedBy=multi-user.target
